# Cresus Folio — données

Historique mensuel des prix des produits scellés Pokémon (TCGplayer, en dollars), lu par le site
[Cresus Folio](https://cresusfolio.web.app) pour tracer l'évolution du prix d'un produit.

- Source : archives publiques de [TCGCSV](https://tcgcsv.com/faq), disponibles depuis le 8 février 2024.
- Fichier : `data/historique-pokemon.json` — `dates` (une par mois) et `p` (prix par identifiant de produit TCGplayer).
- Mise à jour : tâche GitHub `Historique des prix Pokémon`, le 2 de chaque mois (ou à la main via « Run workflow »).
